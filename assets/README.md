# Grafiken

Hier liegen die Platzhalter-Grafiken der App. Ersetze sie durch deine eigenen
(gleiche Dateinamen beibehalten):

| Datei                  | Zweck                        | Empfohlene Größe |
| ---------------------- | ---------------------------- | ---------------- |
| `icon.png`             | App-Icon                     | 1024 × 1024      |
| `adaptive-icon.png`    | Android adaptives Icon       | 1024 × 1024      |
| `splash.png`           | Startbildschirm              | 1284 × 2778      |
| `notification-icon.png`| Icon für Benachrichtigungen  | 96 × 96          |

Tipp: Mit `npx @expo/configure-splash-screen` oder Tools wie
[icon.kitchen](https://icon.kitchen) erzeugst du passende Varianten.
